### P3:
- **类型**：content
- **研究需求**：✅
- **标题**：现有工具碎片化，白板/语音/文件传输彼此独立且公网中转体验差
- **内容概要**：现有工具碎片化：白板（Miro 等）、语音（腾讯会议/Discord 等）、文件传输（微信/网盘等）彼此独立，切换频繁；文件走公网中转时速度受服务端出口带宽与计费策略限制，大文件体验尤其差。
- **研究查询**：仅参考——主流协作工具切换频率与效率损失调研
- **数据需求**：仅参考——公网文件传输速率与局域网对比数据

- **内容概要**：浏览器能力已足以支撑本课题：WebRTC（媒体流与 DataChannel）、Canvas/WebGL、File System Access API 均为稳定标准，"零安装"的实时协作在工程上已可行。
