# 设计系统：科技极简风格

## 1. 视觉主题与氛围

该风格以纯白与柔和浅灰构成克制画布，使界面退居内容之后；所有视觉元素均须服务于信息表达。

字体支持光学尺寸调整。35px 展示标题使用字重 600、行高 1.07 与字间距 -0.28px，强调精确与直接；19px 正文使用字间距 -0.374px、行高 1.47，兼顾紧凑与可读性。

白色（`#ffffff`）与浅灰（`#f5f5f7`）背景交替，均配近黑文字（`#1d1d1f`），形成清晰层级。科技蓝（`#0071e3`）是唯一强调色，仅用于链接、按钮与聚焦状态。

**关键特征：**

- 光学尺寸调整字体系列——字母形态根据尺寸语境自动适应
- 白色与浅灰交替的区域节奏：白色（`#ffffff`）交替浅灰（`#f5f5f7`）
- 单一 accent 色：科技蓝（`#0071e3`）专门保留给交互元素
- 产品主导的 Hero 摄影风格，使用纯色背景，禁用渐变与纹理
- 极度紧凑的标题行高（1.07-1.14）创造出压缩的、广告牌般的影响力
- 全宽区域布局，居中内容——画布充满整个视野
- 药丸形 CTA（980px 圆角）创造柔和、亲切的操作按钮
- 区域之间使用宽裕留白

## 2. 配色方案、色彩角色与图表配色

### 主色

- **纯白**（`#ffffff`）：主区域背景，开阔干净的展示。最亮的画布衬托最清晰的内容。
- **浅灰**（`#f5f5f7`）：交替区域背景，信息区域。轻微的蓝灰色调防止冰冷感。
- **近黑**（`#1d1d1f`）：主要文字色。比纯黑略暖，阅读更舒适。

### 交互色

- **科技蓝**（`#0071e3`）：主 CTA 背景，聚焦环。设计中唯一的彩色。
- **链接蓝**（`#0066cc`）：行内文字链接。比科技蓝略深，文字可读性更好。

### 文字色

- **白色**（`#ffffff`）：科技蓝按钮上的文字，浅色按钮上的强调文字。
- **近黑**（`#1d1d1f`）：浅色背景上的主要正文。
- **黑色 80%**（`rgba(0, 0, 0, 0.8)`）：次要文字。略微柔和。
- **黑色 48%**（`rgba(0, 0, 0, 0.48)`）：三级文字，禁用状态。

### 表面色

- **浅灰表面**（`#f5f5f7`）：卡片和容器的默认背景。
- **微白表面**（`#fafafc`）：搜索/筛选按钮背景，微妙的高度变化。

### 按钮状态

- **按钮激活**（`#ededf2`）：浅色按钮的激活/按下状态。
- **按钮默认浅色**（`#fafafc`）：搜索/筛选按钮背景。
- **遮罩**（`rgba(210, 210, 215, 0.64)`）：媒体控件遮罩，叠加层。

### 图表配色

图表数据系列按以下优先级取色，最多 6 色。

| 优先级 | 色值 | 说明 |
| --- | --- | --- |
| 第一数据系列 | `#0071e3` | 科技蓝（唯一 accent） |
| 第二数据系列 | `#1d1d1f` | 近黑 |
| 第三数据系列 | `#0066cc` | 链接蓝 |
| 第四数据系列 | `#f5f5f7` | 浅灰（用于对比柱/带边框） |
| 第五数据系列 | `rgba(0, 0, 0, 0.8)` | 黑色 80% |
| 第六数据系列 | `rgba(0, 0, 0, 0.48)` | 黑色 48% |

- 坐标轴标签、图例文字、数据标签：使用 `#1d1d1f` 或 `rgba(0, 0, 0, 0.8)`，禁止 `#B5B5B5` 或更淡灰色。
- 分割线/网格线：使用 `#f5f5f7`（浅灰）。
- 柱状图/折线图：纯色填充，无渐变；折线节点可用科技蓝强调。

### 阴影

- **卡片阴影**（`rgba(0, 0, 0, 0.22) 3px 5px 30px 0px`）：产品卡的柔和弥散阴影。偏移量和宽模糊创造出自然、摄影般的阴影效果。

## 3. 字号梯度与排版规则

### 字体系列

- **主字体**：标题、正文与图表统一使用 frontmatter 声明的 `NanxiXinyuanti`, `Noto Sans SC`, `sans-serif` 完整字体栈

### 原则

- **光学尺寸作为哲学核心**：优先使用 `NanxiXinyuanti` 的圆润几何感建立轻科技气质；若该字体不可用，CSS 字体栈会自动降级到 `Noto Sans SC` 或系统无衬线字体，仍保留紧凑行高与克制字重。
- **字重克制**：字重范围从 300（细）到 700（粗），但大多数文字停留在 400（常规）和 600（半粗）。300 字重仅出现在大型装饰文字上。700 字重很少使用，仅用于粗体卡片标题。
- **全尺寸负字间距**：与大多数仅在标题上调整字间距的系统不同，本系统在正文尺寸也应用微妙的负字间距（19px 时 -0.374px，16px 时 -0.224px，14px 时 -0.12px）。这创造了普遍紧凑高效的文字。
- **极端行高范围**：标题压缩到 1.07，正文打开到 1.47，某些按钮语境拉伸到 2.41。这种戏剧性范围仅通过节奏就创造了清晰的视觉层级。

## 5. 布局原则

### 间距系统

- 基本单位：8px
- 刻度：2px, 4px, 5px, 6px, 7px, 8px, 9px, 10px, 11px, 14px, 15px, 17px, 20px, 24px
- 小尺寸（2–11px）以 1px 递增，随后使用更大步长，以支持精细排版与图标对齐。

### 网格与容器

- 最大内容宽度：约 980px（药丸按钮中反复出现的"980px 圆角"呼应了这个宽度）
- Hero区：全宽度区域，居中内容块
- 产品网格：居中容器内的 2-3 列布局
- Hero时刻单列——一个产品，一条信息，全神贯注
- 无可见网格线或排水沟——间距创造隐含结构

### 留白理念

- **大幅留白**：每个内容区域占据或接近全视口高度，以留白分隔场景。
- **通过色块实现垂直节奏**：不使用仅靠间距分隔区域，而是使用交替背景色（白色、`#f5f5f7`）。每次颜色变化都标志着新的"场景"。
- **内部压缩，外部扩展**：文字块紧密设置（负字间距，紧凑行高），而它们周围的空间是广阔的。这在密度和开放之间创造了张力。

### 圆角刻度

- 微型（5px）：小型容器，标签
- 标准（8px）：按钮，产品卡，图片容器
- 舒适（11px）：搜索输入，筛选按钮
- 大（12px）：功能区面板，生活方式图片容器
- 完整药丸形（980px）：CTA 链接（"了解更多"），导航药丸
- 圆形（50%）：媒体控件（播放/暂停，箭头）

### PAGE_CONTENT 纵向布局约束

> 本风格遵守通用契约，详见 [designer.md §PAGE_CONTENT 纵向布局约束（通用契约，所有预设风格适用）]；本节仅列本风格补充。
>
> 关键约束（不重复契约全文）：
> - 根容器：`w-full flex-1 min-h-0`；不修改 `<main>` class。
> - 双列图表 + 信息区：图表列满高不等于视觉均衡，信息短列须显式纵向权重（如 `3fr / 2fr / 5fr`），逐列验收。
> - 同行等权：顶部差与底部差均 ≤ 8px。
> - 图表忠实表达：禁止裁切坐标、扭曲刻度、伪造数据。

## 6. 深度与层次

| 级别 | 处理方式 | 用途 |
| --- | --- | --- |
| 平面（0 级） | 无阴影，纯色背景 | 标准内容区域，文字块 |
| 微妙悬浮（1 级） | `rgba(0, 0, 0, 0.22) 3px 5px 30px 0px` | 产品卡，浮动元素 |
| 聚焦（无障碍） | `2px solid #0071e3` 轮廓 | 所有交互元素的聚焦 |

**阴影理念**：阴影使用极其节制。主阴影（`3px 5px 30px`，0.22 透明度）柔和、宽泛、偏移——模仿漫射工作室灯光在物理物体下方投射的自然阴影。这强化了"内容即物理雕塑"的隐喻。大多数元素根本没有阴影；高度来自背景色对比（浅灰卡片在白色背景上，或白色卡片在稍有不同的浅灰上）。

### 装饰深度

- 区域颜色过渡：深度由白色和浅灰区域之间的交替暗示，而非由阴影暗示
- 产品摄影阴影：内容本身在摄影中投射阴影，因此不需要添加合成阴影

## 7. 该做与不该做

### 该做

- 所有字号统一复用 frontmatter 完整字体栈，仅按层级调整字号、字重、行高与字间距
- 在所有文字尺寸应用负字间距（不仅是标题）——全局紧凑
- 仅将科技蓝（`#0071e3`）用于交互元素——它必须是唯一的 accent
- 在白色和浅灰（`#f5f5f7`）区域背景之间交替，创造清晰的视觉节奏
- CTA 链接使用 980px 圆角——标志性的链接形状
- 图片始终置于纯色背景上，无竞争视觉元素
- 标题行高压缩到 1.07-1.14——标题以紧凑著称

### 不该做

- 禁止引入蓝色体系外的强调色
- 禁止以黑色（`#000000`）或深灰作为区域背景；仅使用白色与浅灰
- 禁止重阴影或多层阴影；最多使用一层柔和漫射阴影
- 卡片与容器禁用可见边框，特定按钮除外
- 禁止宽字间距；各字号均保持紧凑
- 字重不得使用 800 或 900，最大为 700
- 背景仅用纯色，禁用纹理、图案与渐变
- 正文左对齐，不得居中；标题可居中
- 矩形元素圆角不得超过 12px；980px 仅用于药丸形

## 12. 内容页布局规范

内容页必须基于 `content-template.html` 骨架填充，仅替换 `{{PAGE_CONTENT}}` 等占位符。

- **页面容器**：`<div class="ppt-slide flex flex-col" type="content">`，使用 `.content-safe` 内容安全区（1220×660px，四周 30px 边距）。
- **标题栏**：35px 近黑（`#1d1d1f`），字重 600，字距 -0.28px，行高 1.07，下方近黑细线 40×1px；仅修改 `<h1>` 内标题文字。
- **页脚**：14px `rgba(0, 0, 0, 0.48)`，仅修改来源/口径注释文字。
- **内容根容器**：`{{PAGE_CONTENT}}` 替换为唯一一个 `w-full flex-1 min-h-0` 根容器；不得修改 `<main>` 的 class。
- **布局节奏**：优先使用 Flexbox/Grid；同一轴上的同层级模块共用一个间距 token（常规 16–24px，密集 8–16px）；双列横向列间距允许 32px。
- **视觉特征**：区域背景在白色（`#ffffff`）与浅灰（`#f5f5f7`）之间交替；卡片使用 5–8px 圆角，无边框；交互元素统一使用科技蓝（`#0071e3` / `#0066cc`）。
